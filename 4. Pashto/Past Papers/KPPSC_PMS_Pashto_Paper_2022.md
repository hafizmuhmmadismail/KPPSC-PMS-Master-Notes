### سوال نمبر 1: د درست جواب انتخاب اوکړئ (MCQs) [20 نمرې]

1. پټه خزانه د چا کتاب دے؟  
   *(د محمد هوتک / د امیرکرور / رحمان بابا)*
2. د تورې او قلم خاوند چا ته وئیلے شی؟  
   *(شیر شاہ سوری / خوشحال خان خټک / احمد شاہ ابدالی)*
3. د رحمان بابا د پلار نوم څه ؤ؟  
   *(عبدالله / عبدالستار / عبدالغنی)*
4. پښتو کښې موشګاف شاعر چا ته وئیلے شی؟  
   *(حمید / علی خان / کامګار خان)*
5. پښتو کښې د نثر وړومبے کتاب دے؟  
   *(خیرالبیان / مخزن الاسلام / دستار نامه)*
6. “د پنجری چغار” د چا کتاب دے؟  
   *(اجمل خټک / غنی خان / اشرف مفتون)*
7. د حمزه بابا د وړومبی شعری کتاب نوم دے؟  
   *(د زړہ اواز / غزونی / یون)*
8. ملک الشعراء د چا خطاب دے؟  
   *(عبدالله استاذ / حمزہ بابا / سمندر خان سمندر)*
9. “مات بنګړی” کوم صنف دے؟  
   *(ناول / ډرامه / افسانه)*
10. د اجمل خټک کتاب “دا زہ پاګل وم” څه شی دے؟  
    *(سفر نامه / رپورتاژ / ډرامه)*
11. فولکلور څه ته وائی؟  
    *(کلاسکی ادب / رومانوی ادب / اولسی ادب)*
12. جرس مجله د کوم ځائی نه چاپکیده؟  
    *(پېښور / کوئټه / کراچی)*
13. د خوشحال بابا نثری کتاب کوم یو دے؟  
    *(طب نامه / فراق نامه / دستار نامه)*
14. دری یتیمان ډرامه چا لیکلی دہ؟  
    *(عبدالخالق خلیق / عبدالاکبر خان / عبدالودود)*
15. هائیکو د کوم ځائی نه راغلے صنف دے؟  
    *(چین / جاپان / یونان)*
16. “میخانه” د چا ناول دے؟  
    *(سید رسول رسا / شیر زمان غمزجن / رشید علی دهقان)*
17. د پښتو وړومبے ناول “نتیجه عشق” کله لیکلے شوے دے؟  
    *(1910ء / 1911ء / 1912ء)*
18. “لاله زار” د چا کتاب دے؟  
    *(یونس خلیل / همیشه خلیل / حنیف خلیل)*
19. “پښتو ادب کښې کردارنګاري” د چا د پی ایچ ډی مقاله دہ؟  
    *(راج ولی شاہ خټک / محمد اعظم اعظم / اقبال نسیم)*
20. د حمزه بابا ډرامه ژوندہ ګور کښې چا ترجمه کړی دہ؟  
    *(فارغ بخاری / رضا همدانی / خاطر غزنوی)*
