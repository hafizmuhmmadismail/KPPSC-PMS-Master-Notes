
# 🧠 NoteGenius - Smart Study Assistant

## **✨Abstract**
NoteGenius is an intelligent study companion that uses machine learning and natural language processing to analyze your notes (text/PDF) and automatically generate study aids, saving you hours of manual work.

## **✨ Key Features**

### 📝 Multi-Format Note Processing
- **Universal Input Support**: Accepts notes in Text and PDF formats
- **Smart Content Recognition**: text extraction capabilities from PDF

### 🧠 Smart Content Transformation
- **Concise Summaries**: Generate digestible summaries from lengthy notes
- **Interactive Flashcards**: Create flashcards for active recall and spaced repetition
- **Visual Mind Maps**: Build mind maps to visualize topic connections and relationships
- **Memory Mnemonics**: Develop custom mnemonics for enhanced memorization

### 🎯 Study Tools Generation
- **PowerPoint Presentations**: Automatically convert notes to professional presentations
- **Audio Learning**: Text-to-speech conversion for auditory learners
- **Assessment Creation**: Generate quizzes and question banks for self-testing

### Advanced Learning Support
- **Intelligent Q&A**: Get instant answers based on your uploaded notes
- **Resource Recommendations**: Receive curated video and material suggestions
- **Knowledge Gap Analysis**: Identify areas needing additional study focus

## **🚀Installation and usage**
- Clone the repository using
  ```
  git clone https://github.com/AAC-Open-Source-Pool/25AACL05
  ```
- Install all the dependencies using
  ```
  pip install -r requirements.txt
  ```
- Run all the features one after the other
- Now run app.py
- Then upload your notes and choose the feature you want to explore and use
- Desired output will be generated
  
<br>

### 📋 Supported Input Formats

| Format | Description | Processing Method |
|--------|-------------|-------------------|
| **Text**  | Plain text | Direct NLP processing |
| **PDF** (.pdf) | Portable document format | Advanced text extraction |

<br>

### 🎯 How It Works

1. **Upload**: Submit your notes in any supported format (text, PDF)
2. **Process**: AI analyzes content using advanced NLP and ML models
3. **Generate**: Automatically creates personalized study materials
4. **Study**: Access flashcards, summaries, quizzes, and mind maps

<br>

### 🌟 Benefits

- **Time-Saving**: Automate hours of manual study material creation
- **Enhanced Learning**: Multiple learning modalities in one platform
- **Improved Retention**: Evidence-based study techniques and spaced repetition
- **Personalized Experience**: AI-driven recommendations and adaptive learning
- **Comprehensive Analysis**: Deep understanding of your study materials

<br>

### 📊 Use Cases

- **Students**: Transform lecture notes into comprehensive study guides
- **Professionals**: Create training materials from documentation
- **Researchers**: Process and synthesize large volumes of academic content
- **Educators**: Generate teaching materials and assessments
