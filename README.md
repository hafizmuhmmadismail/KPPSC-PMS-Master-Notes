## 📐 The Institutional 5-Page Standard Architecture

Every single master note in this repository adheres strictly to an unyielding 7-section blueprint. Below is the exact format present in every file:

```
┌────────────────────────────────────────────────────────────────────────┐
│  1. UNIFIED METADATA HEADER & VERBATIM PAST PAPER MATRIX               │
│     - Formal Academic Question Title                                   │
│     - EXAM QUESTIONS LINKED (Verbatim quotes from 2008–2025 papers)    │
│     - Core Syllabus Theme & Section                                    │
│     - Primary Historiographical / Theoretical Lens                     │
├────────────────────────────────────────────────────────────────────────┤
│  2. EXECUTIVE EXAM TAKEAWAYS (3 to 5 Punchy Thesis Assertions)         │
├────────────────────────────────────────────────────────────────────────┤
│  3. CONCEPTUAL FLOWCHART / MIND MAP (Monospace ASCII Causal Pathway)   │
├────────────────────────────────────────────────────────────────────────┤
│  4. CHRONOLOGY / COMPARATIVE MATRIX (Structured Analytical Table)      │
├────────────────────────────────────────────────────────────────────────┤
│  5. COMPREHENSIVE ESSAY BODY (2,200 – 2,800 Words)                     │
│     - Academic Introduction with Historiographical / Theoretical Hook │
│     - 6 to 8 Thematic Bold Headings & Numbered Subheadings             │
│     - Deep Empirical Evidence: Treaties, Data, Precedents, Conventions │
│     - Academic Conclusion with Forward-Looking Synthesis               │
├────────────────────────────────────────────────────────────────────────┤
│  6. HISTORIOGRAPHICAL & THEORIST QUOTATION BANK (5 Verbatim Quotes)    │
│     - Exact Scholar Name, Seminal Work, Publication Year, Quote & Use  │
├────────────────────────────────────────────────────────────────────────┤
│  7. STRATEGIC EXAM RECOMMENDATIONS & EXAMINER TRAPS TO AVOID           │
│     - 3 Common Candidate Pitfalls / Traps to Avoid                     │
│     - 3 High-Scoring Strategies & Technical Diagram Recommendations    │
└────────────────────────────────────────────────────────────────────────┘
```

## 🧠 The AI Agent & Skill Architecture

This repository is powered by a custom-engineered AI Agentic framework developed using Google Antigravity, custom skills, and Python Wordcraft engines.

### 1. Agents (`.agents/agents/`)
- **[`pms-notes-architect`](.agents/agents/pms-notes-architect/agent.md)**:
  - An elite academic system prompt configured to think like a senior civil service examiner and Oxford/Cambridge historiographer.
  - Automatically decomposes multi-decade past papers, clusters rephrased questions, and enforces the 5-page ceiling and 2,500-word academic rigor.

### 2. Custom Skills (`.agents/skills/`)
- **[`pms-exam-notes-processor`](.agents/skills/pms-exam-notes-processor/SKILL.md)**:
  - Coordinates PDF document ingestion, text cleaning, syllabus extraction, chronological mapping, and past paper frequency weighting.
- **[`templates/PMS_MASTER_NOTE_STANDARD_SPECIFICATION.md`](templates/PMS_MASTER_NOTE_STANDARD_SPECIFICATION.md)**:
  - The binding architectural specification guaranteeing that all generated notes maintain identical heading hierarchies, table widths, and quote structures.

### 3. Automation Toolkits (`apps_toolkit/`)
- **Wordcraft Native Engine Integration**:
  - Converts markdown and structured JSON data into native Microsoft Word (`.docx`) documents with an institutional palette:
    - Primary Deep Navy: `#0E2B50`
    - Secondary Steel Blue / Teal: `#1B4965`
    - Callout Neutral Fill: `#F0F4F8`
    - Monospace Mindmaps: `Consolas` font
    - Margins: Exactly 0.8 inches with 1.15 line spacing.
- **PDF Compilation**:
  - Produces clean, print-ready PDFs with zero layout shift and embedded header/footer page numbers (`Page X of Y`).

## 💻 How to Use This Repository

### For Civil Service Aspirants & Colleagues:
1. **Direct Web Reading**:
   - Open any `.md` file directly on GitHub. Every note is fully rendered with styled callouts, ASCII diagrams, markdown tables, and citations.
2. **Notion / Obsidian Sync**:
   - Clone or download the repository to import the `.md` files directly into Obsidian or Notion for personal knowledge management (PKM) and cross-linking.
3. **Print-Ready Revision (Word / PDF)**:
   - Download the `.docx` or `.pdf` files from each subject folder for double-sided spiral printing and physical highlighter study.
4. **Exam Hall Time Budgeting**:
   - In a 3-hour PMS exam, candidates must answer 5 questions (36 minutes per question).
   - Use **Section 2 (Executive Takeaways)** and **Section 3 (Mind Maps)** to plan your outline on your rough sheet in the first 3 minutes.
   - Deploy **Section 4 (Comparative Tables)** and **Section 6 (Quotation Bank)** in the body to make your script immediately stand out to the examiner.
